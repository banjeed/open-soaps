# Open Source Soap Recipes

A free, community-maintained library of cold-process soap recipes. Browse, make, adapt, and share.

---

## How to find a recipe

**By scent family** — browse the `recipes/` folder. Each subfolder is a scent category:

| Folder | Examples |
|---|---|
| `floral/` | Rose, lavender, jasmine |
| `citrus/` | Lemon, orange, grapefruit |
| `earthy/` | Patchouli, clay, charcoal |
| `woody/` | Cedar, sandalwood, pine |
| `herbal/` | Peppermint, rosemary, eucalyptus |
| `unscented/` | Fragrance-free and sensitive-skin bars |

**By base oil** — use GitHub search. Each recipe file has a `base_oil:` tag in its header. Example search:

```
base_oil: olive  repo:yourusername/soap-recipes
```

Common base oils tagged across recipes: olive, coconut, shea, castor, avocado, palm-free, lard, tallow.

---

## Recipe format

Every recipe file includes:
- A YAML front matter block with metadata and tags
- A full ingredient list with weights in grams
- Step-by-step process instructions
- Lye calculation details and superfat %
- Cure time and yield
- A version changelog
